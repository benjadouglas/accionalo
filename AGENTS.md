## Cursor Cloud specific instructions

`accionalo` is a single, fully static Next.js 16 (App Router, Turbopack) site — an art-studio portfolio that renders a mosaic of tiles linking to per-tile detail pages. There is no backend, database, environment variables, or external services; running the dev server is all that's needed to work on it.

- Package manager is npm (see `package-lock.json`). Dependency install is handled by the startup update script, so you normally don't need to run it manually.
- Standard commands live in `package.json` scripts: `npm run dev` (dev server on http://localhost:3000), `npm run build`, `npm run start` (needs a prior build), and `npm run lint` (ESLint).
- The `nextjs-agent-rules` block above is regenerated by `next dev`; committing it alongside your changes keeps the tree clean (do not fight the re-add).
